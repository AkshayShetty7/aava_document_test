1. Getting Started
Java is a general-purpose, class-based programming language. Java source code is compiled into bytecode, which
runs on a Java Virtual Machine (JVM). A Java Development Kit (JDK) includes tools to compile and run programs.
Your first program
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, world!");
        System.out.println(2 + 3);
    }
}
Save this code in a file named Main.java. Compile it with javac Main.java, then run it with java Main. The
public class name and file name must match.
Understanding the structure
class Main defines a class. The main method is the usual entry point for a standalone Java application. Braces { }
mark blocks, and most statements end with a semicolon.
Printing and comments
System.out.print("Same line ");
System.out.println("then a new line");
// Single-line comment
/* Multi-line
   comment */
Java is case-sensitive: main and Main are different identifiers. Use consistent indentation to make blocks easy to
read.
Tip: install a JDK from a trusted distribution and check it is available with java -version and javac -version.

2. Variables, Types, and Operators
Java is statically typed: declare a variable’s type before using it. Local variables generally need to be assigned
before they are read.
int age = 19;
double price = 49.95;
char grade = 'A';
boolean enrolled = true;
String name = "Kiran";
Primitive types include byte, short, int, long, float, double, char, and boolean. String is a class used for text, not a
primitive type. Java statements commonly end with semicolons.
Constants and naming
final double PI = 3.14159;
int studentCount = 35;
The final keyword prevents reassignment after a variable is initialized. Use meaningful names such as
studentCount; Java variable names conventionally use lower camelCase.
Arithmetic operators
int a = 10, b = 3;
System.out.println(a + b);  // 13
System.out.println(a - b);  // 7
System.out.println(a * b);  // 30
System.out.println(a / b);  // 3 (integer division)
System.out.println(a % b);  // 1
System.out.println(a * 1.0 / b); // decimal result
When both operands of / are integers, Java performs integer division and discards the fractional part. Use a
floating-point operand when you need a decimal result.
Comparisons and logic
int score = 82;
System.out.println(score >= 50); // true
System.out.println(score == 82); // true
System.out.println(score != 0);  // true
boolean hasId = true;
System.out.println(score >= 50 && hasId);
Comparison operators include ==, !=, <, >, <=, and >=. Logical operators are && (and), || (or), and ! (not). For
objects such as String, use equals() to compare text content rather than ==.

3. Decisions and Loops
if / else if / else
int mark = 76;
if (mark >= 90) {
    System.out.println("A");
} else if (mark >= 70) {
    System.out.println("B");
} else {
    System.out.println("Keep practising");
}
Conditions must evaluate to a boolean. Java checks branches in order and executes the first matching branch.
switch
int day = 2;
switch (day) {
    case 1:
        System.out.println("Monday");
        break;
    case 2:
        System.out.println("Tuesday");
        break;
    default:
        System.out.println("Another day");
}
In this traditional switch form, break prevents execution from falling through into the next case. default handles
values that do not match a case.
for and while loops
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
int count = 3;
while (count > 0) {
    System.out.println(count);
    count--;
}
A for loop is useful when the iteration pattern is known. A while loop repeats as long as its condition is true. Make
sure the condition eventually becomes false to avoid an infinite loop.
break and continue
for (int n = 0; n < 6; n++) {
    if (n == 2) continue; // skip 2
    if (n == 5) break;    // stop at 5
    System.out.println(n);
}
Exercise: change the loop so it prints only even numbers from 2 through 10.

4. Arrays, Strings, and Methods
Arrays
int[] marks = {78, 91, 84};
System.out.println(marks[0]); // 78
marks[1] = 95;
System.out.println(marks.length); // 3
for (int mark : marks) {
    System.out.println(mark);
}
An array holds a fixed number of elements of one type. Indexes start at 0; the last valid index is length - 1.
Accessing an invalid index causes an ArrayIndexOutOfBoundsException.
Strings
String language = "Java";
System.out.println(language.length());
System.out.println(language.toUpperCase());
System.out.println(language.equals("Java"));
String objects are immutable: methods such as toUpperCase() return a string rather than changing the original. Use
equals() for content comparison.
Methods
public static int add(int x, int y) {
    return x + y;
}
public static void main(String[] args) {
    int result = add(4, 6);
    System.out.println(result); // 10
}
A method groups reusable code. Parameters are inputs; the return type describes the result. void means the
method does not return a value. In a class, methods can be called from other methods subject to access and
static/instance rules.
Collections preview
import java.util.ArrayList;
ArrayList<String> names = new ArrayList<>();
names.add("Asha");
names.add("Dev");
System.out.println(names.get(0));
An ArrayList can grow or shrink as elements are added or removed, unlike a fixed-size array. The import statement
belongs at the top of the source file, before the class declaration.

5. Classes, Input, and Exceptions
Classes and objects
class Dog {
    String name;
    Dog(String name) {
        this.name = name;
    }
    void bark() {
        System.out.println(name + " says woof");
    }
}
// Example use inside a main method:
Dog pet = new Dog("Milo");
pet.bark();
A class defines fields (state) and methods (behaviour). An object is an instance of a class. A constructor initializes
an object; this.name refers to the field, while name is the parameter.
Read input with Scanner
import java.util.Scanner;
Scanner input = new Scanner(System.in);
System.out.print("Enter your age: ");
int age = input.nextInt();
System.out.println("Next year: " + (age + 1));
input.close();
Place the import at the top of the file and the remaining statements inside main. Scanner provides methods such as
nextInt() and nextLine(). Be aware that nextInt() leaves the line break behind; mixing it with nextLine() may require
consuming that newline.
Basic exception handling
try {
    int value = Integer.parseInt("123");
    System.out.println(value);
} catch (NumberFormatException ex) {
    System.out.println("Not a valid integer");
}
Exceptions represent problems encountered during execution. Use try/catch when you can recover or provide a
useful response. Do not silently ignore errors.
